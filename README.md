# Octa Leads Landing Page

Projeto React + Vite para a landing page da Octa Leads.

## Como usar

1. Instale dependências:
   ```bash
   npm install
   ```
2. Execute em modo de desenvolvimento:
   ```bash
   npm run dev
   ```
3. Abra o link mostrado no terminal.

## Observações

- A imagem do logo está em `public/logo-octa-leads.png`.
- Ajuste `WHATSAPP_NUMBER`, `INSTAGRAM_URL`, `BUSINESS_EMAIL` e `CITY_STATE` diretamente em `src/App.jsx`.
